# Case Study 3: Echo Show 8 IoT Evidence Investigation
**Project Overview**
This project documents a digital forensic investigation of an authorised Amazon Echo Show 8 training dataset. The investigation focuses on eMMC and userdata images to identify device information, user-related artefacts, network activity, communication records, multimedia, and event chronology.

The aim is to produce evidence-based findings while preserving evidence integrity and documenting investigative limitations.

**Objectives**
1. Verify evidence integrity and document image provenance.
2. Examine device configuration, operating system, and internal storage.
3. Analyse user-related data, applications, and system logs.
4. Investigate network connectivity and web activity.
5. Examine available phone communication and multimedia artefacts.
6. Reconstruct a 24–72-hour timeline and validate findings against source evidence.
   
**Methodology**
1. Register evidence and verify available checksums.
2. Examine verified copies using approved forensic tools.
3. Identify relevant files, databases, logs, and metadata.
4. Analyse timestamps and correlate independent artefacts.
5. Manually validate at least one tool-generated result.
6. Document findings, limitations, and alternative explanations.


**Tools**
Tools may include forensic image viewers, hashing utilities, SQLite database viewers, file metadata utilities, and timestamp analysis scripts. Actual tools and versions will be documented in the final report.

**Evidence Handling**
1. Preserve original evidence and work on verified copies.
2. Use approved, read-only examination methods where possible.
3. Record source paths, hashes, timestamps, tools, and versions.
4. Do not upload raw evidence or sensitive extracted data to GitHub.
5. Distinguish verified facts from inferences and unknowns.
   
**Conclusion**
The investigation aims to establish what the supplied training evidence supports about Echo Show 8 device activity. Conclusions will remain within the limits of the available artefacts and will not assume that device activity proves the identity or intent of a particular person.
